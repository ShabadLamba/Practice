# Interview Preparation Repository

A comprehensive collection of interview preparation materials, practice problems, and projects for frontend development interviews.

## 📚 Repository Structure

This repository is organized into the following sections:

### 🅰️ Angular Problems
**Location:** `angularProblems/interview-practice/`

A complete Angular project setup for practicing Angular-specific interview questions and concepts.

- **Framework:** Angular (with Server-Side Rendering support)
- **Language:** TypeScript
- **Build Tool:** Angular CLI

**Getting Started:**
```bash
cd angularProblems/interview-practice
npm install
npm start
```

### ⚛️ React Problems
**Location:** `reactProblems/interview-practice/`

A modern React project setup using Vite for practicing React interview questions and building components.

- **Framework:** React
- **Language:** TypeScript
- **Build Tool:** Vite
- **Linting:** ESLint

**Getting Started:**
```bash
cd reactProblems/interview-practice
npm install
npm run dev
```

### 📝 JavaScript Problems
**Location:** `javascriptProblems/`

Pure JavaScript coding challenges and problem-solving exercises commonly asked in technical interviews.

### 🎨 Frontend System Design Blogs
**Location:** `frontendSystemDesignBlogs/`

Notes, articles, and resources related to frontend system design concepts for senior-level interviews.

### 🌐 Web Fundamentals Blogs
**Location:** `webFundamentalsBlogs/`

Core web development concepts, best practices, and fundamental knowledge required for frontend interviews.

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ShabadLamba/Practice.git
   cd Practice
   ```

2. **Choose your practice area:**
   - For Angular: Navigate to `angularProblems/interview-practice/`
   - For React: Navigate to `reactProblems/interview-practice/`
   - For JavaScript: Browse `javascriptProblems/`

3. **Install dependencies** (for Angular/React projects):
   ```bash
   npm install
   ```

4. **Start development:**
   - Angular: `npm start`
   - React: `npm run dev`

- Web Fundamentals (HTML, CSS, JavaScript)
